# Data Structure Operations Guide

## Overview

DataVerse is an interactive platform for experimenting with data structures and algorithms. This guide describes common operations associated with the major data structures.

## 1. Array

An array stores elements in an indexed sequence.

- **Insertion:** Add an element at a specified position.
- **Deletion:** Remove an element from a specified position.
- **Traversal:** Visit and display each element.
- **Searching:** Find an element by its value.

## 2. Linked List

A linked list consists of nodes connected through links.

- **Insertion:** Add a node at the beginning, end, or a specified position.
- **Deletion:** Remove a node from the list.
- **Traversal:** Visit nodes from the head to the end.
- **Reversal:** Reverse the order of the nodes.

## 3. Stack

A stack follows the Last In, First Out (LIFO) principle.

- **Push:** Add an element to the top.
- **Pop:** Remove the top element.
- **Peek:** View the top element without removing it.
- **Display:** Show the stack elements.

## 4. Queue

A standard queue follows the First In, First Out (FIFO) principle.

- **Enqueue:** Add an element to the rear.
- **Dequeue:** Remove an element from the front.
- **Front:** View the front element.
- **Display:** Show the queue elements.

## 5. Tree

A tree organizes data in a hierarchical structure.

- **Insertion:** Add a node according to the tree's rules.
- **Searching:** Find a node with a specified value.
- **Inorder traversal:** Visit left subtree, node, then right subtree.
- **Preorder traversal:** Visit node, left subtree, then right subtree.
- **Postorder traversal:** Visit left subtree, right subtree, then node.

Note: The traversal orders above describe a binary tree. In a Binary Search Tree, inorder traversal visits values in sorted order.

## 6. Graph

A graph represents vertices connected by edges.

- **Add vertex:** Add a vertex to the graph.
- **Add edge:** Connect two vertices.
- **Breadth-First Search (BFS):** Explore vertices level by level.
- **Depth-First Search (DFS):** Explore a path deeply before backtracking.

## 7. Hashing

Hashing uses a hash function to map keys to locations in a hash table.

- **Insertion:** Store a key or value.
- **Searching:** Find a stored key.
- **Deletion:** Remove a key.
- **Collision handling:** Manage cases where multiple keys map to the same location.

## Conclusion

Understanding these operations helps users learn how data structures store, organize, and process information.

**Note:** This document describes standard data structure operations. Check the current DataVerse implementation before assuming every listed operation is available in the application.
